# NotEnoughFakepixel — Fabric Port

Native Fabric port targeting Minecraft 1.21.11.

- Minecraft: 1.21.11
- Fabric Loader: 0.19.3+
- Fabric API: 0.141.6+1.21.11
- Java: 21

The 1.8.9 Forge implementation is the feature reference. This repository uses native Fabric APIs instead of trying to load Forge classes on modern Minecraft.

Build with `gradle build`. GitHub Actions builds the remapped client JAR on every push.
